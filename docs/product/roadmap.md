# 产品路线图

## 当前阶段

当前目标是完成 POC，验证一条端到端、可审计、管理员与 AI 能力对等的招聘链路。

```text
申请人提交申请
→ 管理员查看申请
→ 管理员或 AI 推进申请状态
→ 管理员和 AI 查看相同的最新状态
→ 系统记录状态事件和审计记录
```

### POC 验收条件

1. 申请人能够创建并提交申请。
2. 管理员能够登录并查看申请列表和详情。
3. 管理员能够通过后台推进申请状态并填写原因。
4. AI 能通过结构化工具完成相同的查看和状态推进操作。
5. 两种入口执行相同的权限和状态校验。
6. 所有状态变化都能追溯执行主体、渠道、前后状态、原因和时间。

## 后续阶段

POC 验证通过后，按业务价值逐步增加：

1. 文件上传、私有访问和安全扫描。
2. 邮件及站内通知。
3. Demo 预约和评价。
4. 入职与教师状态管理。
5. 每周可授课时间。
6. 工资周期、工资项目和奖励。
7. 渠道分析和运营看板。
8. 需要可靠异步任务时再引入 Redis 和 Celery。

具体交付状态由 GitHub Milestones、Epics 和 Issues 管理；本文件只保存阶段目标和顺序，不复制动态任务列表。
